# MN Privacy Field Guide

A mobile-first GitHub Pages site about everyday surveillance, privacy risks, and practical privacy habits.

## Pages

- Guide: searchable cards about common surveillance/data systems
- Exposure Check: simple privacy exposure quiz
- Resources: law and public-interest reference links

## Deploy on GitHub Pages

1. Upload all files to a public GitHub repository.
2. Go to Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main, folder: /root.
5. Save.

Suggested repo name:

`mn-privacy-field-guide`

Expected URL:

`https://ambokman.github.io/mn-privacy-field-guide/`
